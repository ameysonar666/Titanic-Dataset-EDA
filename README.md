# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)

This project performs Exploratory Data Analysis (EDA) on the famous Titanic dataset to uncover patterns, trends, and factors that influenced passenger survival during the Titanic disaster.

The analysis is performed using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn in a Jupyter Notebook environment.

---

## 📌 Project Objectives

- Understand the structure of the Titanic dataset
- Perform data cleaning and preprocessing
- Handle missing values
- Analyze survival patterns
- Visualize relationships between different features
- Extract meaningful insights from the data

## 📊 Exploratory Data Analysis Performed

### 1. Data Understanding

- Shape of dataset
- Data types
- Statistical summary
- Duplicate value check
- Null value analysis

### 2. Data Cleaning

- Handling missing values
- Removing unnecessary columns
- Data formatting

### 3. Univariate Analysis

Analysis of individual columns such as:

- Age Distribution
- Gender Distribution
- Passenger Class Distribution
- Fare Distribution

### 4. Bivariate Analysis

Relationship between two variables:

- Survival vs Gender
- Survival vs Passenger Class
- Survival vs Age
- Survival vs Fare

### 5. Multivariate Analysis

Combined analysis of multiple features to identify deeper patterns.

### 6. Visualization

Various plots and charts were used:

- Countplots
- Histograms
- Boxplots
- Heatmaps
- Pairplots
- Barplots
